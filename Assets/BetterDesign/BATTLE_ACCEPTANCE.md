# 对战修复与验收
基线：e5125ffa0621782005cce57439dcea9e78a49e9d。Unity 2022.3.29f1 / TMP 3.0.6。所有代码和场景修改均在 Assets/BetterDesign。

## 本轮发现和修复
| 问题 | 对玩家的影响 | 修复与验证 |
| --- | --- | --- |
| 原 7000msyhbdallicon SDF 不包含数字、英文字母和部分常用字 | 血量、按键、物品数量和提示不完整，无法判断操作和伤害是否生效 | 主字体仍引用原资源；SceneFontFallback 仅为缺字使用原有 3500 字库及 LiberationSans。原字体和 TMP 全局配置均不修改。校验字形覆盖，并将 TMP 生成的实际字符逐个还原，与原文比较，防止富文本标签被当作文字显示 |
| 攻击仅使用 GetKeyDown/GetMouseButtonDown，动作锁定时指令丢失 | 长按只打一次，恢复期间按下无反应 | 攻击/法术支持长按；加入 180 ms 输入缓冲；技能按冷却自动重复 |
| 没有鼠标瞄准，朝向只来自移动 | 朝目标点击却向上次移动方向攻击 | 注入场景相机和 IAimedPlayerInput；攻击方向与移动独立；瞄准指示和 Sprite 翻转跟随面向 |
| 项目 Submit 绑定空格，面板关闭后仍保留按钮选中状态 | 空格攻击可能再次触发背包/暂停按钮 | HUD 和输入都显式引用本场景 EventSystem；面板切换清理旧选择；回归验证关闭后选中对象为空 |
| 投射物从前方 0.6 单位生成且只查帧末位置 | 贴身目标、低帧率及前后排列目标可能漏判或先打远处目标 | 发射偏移减为 0.2；按上一位置到下一位置的线段扫掠，优先最近交点目标 |
| 缺乏伤害与进攻反馈 | 无法区分未命中、硬直、击杀 | 给 17 个角色实际布置血条、攻击提示，玩家增加瞄准提示；命中红闪和敌人击退；死亡/回收重置显示 |
| 动作锁定期间无法闪避取消 | 无法主动应对敌人前摇 | 闪避优先级高于未完成攻击/技能；取消未结算命中，保留无敌保护；死亡仍不可转换 |
| 敌人只朝玩家中心走 | 重叠成团，辨识和操作困难 | 增加小规模邻居分离转向，攻击仍朝向玩家；攻击前摇有方向提示，可移出范围躲避 |
| 弓箭仍播放持剑表现 | 武器、动作和命中反馈不一致 | 配置独立 Bow Controller、Idle/Run BlendTree 与射击片段；复制片段去除旧 Shoot 动画事件；武器切换只在动作空闲时生效 |
| 架构面板默认遮挡右侧战区 | 敌人可能被面板遮住 | 默认隐藏，F1 主动打开 |

场景现在包含 629 个预置 GameObject、17 个角色、48 个特效槽、64 个掉落槽、49 个 TMP 标签和 22 个按钮。血条、攻击指示、瞄准指示、字体资源与相机/EventSystem 引用均已序列化，玩法代码不通过工厂搭建场景或面板。TMP 自身为不同字体生成渲染子网格属于字体渲染流程。

## 实际执行的回归
Unity Test Runner：**64 total / 64 passed / 0 failed**。新增 BattleAcceptanceTests 12 项：
- 恢复期间的攻击输入会在可操作后执行；
- 鼠标瞄准方向可以与移动相反；
- 闪避取消未结算攻击；
- 贴身弓箭扫掠优先命中近目标；
- 敌人前摇可见，移出范围可以躲避；
- 连续近战完成首波且玩家存活；
- 自动瞄准/走位的弓箭和法术分别完成整波；
- 敌人血条随生命变化并在重用后重置；
- 指定主字体配合缺字回退，最终字符与原文一致；
- 关闭面板后无残留按钮选择；
- 切弓切剑的 Animator Controller 与武器一致。

整波远程测试使用场景中已有的角色和正常 GameModel.UsePotion 命令，允许消费初始治疗补给，没有直接加血、修改伤害或关闭敌人 AI。输入来自可重复的 IPlayerInput/IAimedPlayerInput 脚本驱动；它证明真实控制器、AI、攻击与掉落链路，不能等同于人工键鼠试玩。

另外已使用有图形设备的 Unity 相机实际渲染检查：标题、生命、数字、输入提示、敌人血条和战斗区域可见；架构面板默认不遮挡战区。不是仅依据程序集编译、字体 GUID 或字符表判定画面正确。四个程序集亦完成 Roslyn 编译。

## 玩家复验路径
1. 拉取分支，打开 Assets/BetterDesign/Scenes/BetterDesignDemo.unity，点击 Play 和 Game 视图。失焦自动暂停时先 Esc 返回。
2. WASD 移动，鼠标指向目标；按住左键或空格连续近战，观察敌人血条和红闪。
3. 结束当前动作后 R 切弓，保持鼠标指向目标并长按左键；确认角色变为弓手，箭沿瞄准方向飞行，贴身射击可命中。
4. 按住 Q 或右键持续施法；Shift 在敌人前摇或自身攻击中闪避，观察取消与无敌窗口。
5. Tab 打开背包，点击格子、关闭，随后按空格；确认没有重新弹出面板。
6. H 使用补给；清完一波确认掉落拾取和清场提示，再 N 开始下一波；F5/F9 检查武器与战局恢复。
7. 分别在 16:9、16:10 和较小 Game 窗口下检查 HUD 与字体，F1 检查状态和池指标。

仍需目标设备人工验收手感、键鼠焦点、不同窗口布局和持续多波体验；本轮未更改原 RPG1 或宣称完成其全部内容迁移。

## 朝向与拖拽回归
基线 9b87625313e95ff6e4ed948e2caec9b0f6374bd9。
- 复现：鼠标持续标记为瞄准，使静止鼠标覆盖走路朝向；动画片段也可能覆盖 SpriteRenderer.flipX。修复为非攻击移动跟随移动、静止保留朝向、攻击/施法跟随鼠标；LateUpdate 将模型翻转应用到 Sprite。剑弓切换和跨帧翻转已有测试。
- 背包原有按钮操作没有实现拖放。12 个实际场景格子现绑定 BeginDrag/Drag/Drop/EndDrag；拖拽图标已预置，不拦截射线。
- InventoryModel 拥有换格事务：空格移动、异类交换、同类按上限合并；无效/满堆叠操作不改变 Revision。InventoryChanged 在提交后通知，UI 不拥有物品数据。
- 拖出、关闭面板、失焦、拖动中背包版本变化会取消；重复打开不会叠加订阅。换格后的完整格子位置进入原有存档。
- 新增 10 项测试，现有 Play Mode 烟测增加跨帧左右翻转检查；总计 64/64 通过。
- 人工复验：鼠标停在右侧，按 A/D 后松开应保持最后方向；持弓按住左键，移动可与瞄准相反。Tab 后将首格补给拖到空格，再拖向蘑菇应交换；丢弃部分补给后重新拾取构造同类格，验证合并与余量。F5/F9 检查位置保留。
